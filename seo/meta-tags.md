## NOTES FOR YOAST SEO SETUP

1. In WordPress, go to each page/post
2. Scroll to the Yoast SEO panel below the editor
3. Click "Edit snippet"
4. Enter the SEO title in the "SEO title" field
5. Enter the meta description in the "Meta description" field
6. Yoast will show you a green/yellow/red indicator for length — aim for green
7. Set the focus keyphrase to the primary keyword listed for each page (see `keyword-targets.md`)
